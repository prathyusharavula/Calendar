📅 Dynamic Calendar
Built a dynamic calendar web application using HTML, CSS, and JavaScript. The application automatically displays the current month, year, and dates using JavaScript's Date object and DOM manipulation techniques.

Features
Display current month and year dynamically
Generate calendar dates automatically
Previous and Next month navigation
Highlight the current date
Responsive user interface
Handles different month lengths and leap years

Technologies Used
HTML5
CSS3
JavaScript (DOM Manipulation)

Key Learning Outcomes
JavaScript Date Object
DOM Manipulation
Event Handling
Dynamic UI Rendering
Calendar Date Logic

Project Description
Developed an interactive calendar application that dynamically renders the current month, year, and dates. Implemented month navigation, date calculations, and responsive design to enhance user experience while strengthening JavaScript DOM manipulation skills.
